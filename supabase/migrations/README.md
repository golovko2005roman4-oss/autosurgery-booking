# Миграции Supabase

DDL-схема (таблицы `services`, `clients`, `vehicles`, `bookings`, `settings`,
уникальный индекс защиты от двойного бронирования, RLS-политики и RPC)
будет создана отдельным этапом по docs/requirements.md, раздел 8.

На текущем этапе каркаса миграции не добавляются сознательно —
БД пока не разворачивается.
